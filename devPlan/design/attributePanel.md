# 属性面板（左下角）展示规则

## 1. 面板概述

- 位置：1920×1080 下左下角 x 24~456，y 837~1080；尺寸 432×243（16:9）
- 纯展示面板，无升级、出售等交互
- 点选单位或建筑时显示，点空白处隐藏
- 无内容的区域隐藏，后续内容紧凑补位
- 独立场景：`scenes/ui/attribute_panel.tscn`
- 控制器：`scripts/adapters/godot/ui/AttributePanelController.cs`
- 挂载点：`scenes/main/main_game.tscn` 的 `UI/AttributePanel`

## 2. 视觉与信息层级

- 深色半透明卡片、浅色描边和阴影，与战场保持清晰分层
- 顶部依次展示头像、名称、副标题和费用/价值徽章
- 生命条紧邻身份区，显示当前值/最大值，不显示百分比
- 核心属性使用两列动态图标网格，不使用文字区域标题
- 底部由技能栏或建筑进度区占用，两者不会同时留空占位
- 所有详细换算和攻防修正通过悬停浮窗展示

## 3. 通用区域

| 区域 | 单位 | 建筑 |
|------|------|------|
| 头像 | 单位立绘，缺失时占位图 | 建筑贴图，缺失时占位图 |
| 名称 | 单位中文名 | 建筑名 |
| 副标题 | 阵营·种族·隐身/伏击/狂怒 | 阵营·工作/休眠/暂停/禁止组合/仪式中 |
| 徽章 | 单位费用 | 建筑价值 |
| 生命条 | 当前生命/最大生命 | 当前生命/最大生命 |

## 4. 单位属性区

| 属性 | 显示 | 悬停明细 |
|------|------|----------|
| 攻击 | 攻击值·近战/远程·伤害类型 | 对各护甲类型不为 100% 的伤害修正 |
| 元素 | 神圣伤害显示神圣元素图标 | 元素名 |
| 护甲 | 有效护甲值·护甲类型 | 护甲减伤与受到各伤害类型的非 100% 修正 |
| 攻击间隔 | 秒数 | 攻击间隔 |
| 射程 | 游戏单位 | 攻击射程 |
| 移动速度 | 游戏单位 | 移动速度 |
| 视野 | 游戏单位 | 是否可侦测隐身 |
| 护盾 | 当前护盾值，仅有护盾时显示 | 当前护盾值 |

治疗单位在攻击位置显示治疗量。属性网格按实际内容紧凑排列。

## 5. 技能区

- 技能图标位于面板底部，悬停显示技能名与描述
- 冷却中的技能显示顺时针遮罩、边缘亮线和剩余秒数
- 没有技能时技能区隐藏，属性区自动获得剩余空间

## 6. 建筑属性区

| 属性 | 规则 |
|------|------|
| 类型 | 核心建筑或普通建筑 |
| 占地 | 实际占用格数 |
| 产出 | 产出单位名与单次生产成本；无产出时显示“不产出单位” |
| 生产 | 有效生产率与配置生产间隔 |
| 生产进度 | 实时进度条、当前状态和预计剩余秒数 |
| 仪式进度 | 仪式名、实时进度条和剩余秒数，优先于生产进度 |

有效生产率包含建筑当前工作倍率和全局生产倍率，可反映邻接等运行时加成。

## 7. 数值规则

- 护甲减伤率 = 护甲值 ÷ (|护甲值| + 15)，浮窗按四舍五入显示百分比；负护甲显示负数
- 攻防矩阵只展示不为 100% 的倍率，正值为 +x%，负值为 -x%
- 多元素攻击按所有元素抗性的最小值结算
- 面板只展示真实数据，不为缺失字段推造数值

## 8. 暂未展示的数据缺口

- 单位伤害抗性：`unit_stats` 和运行时端口暂无字段
- 攻击元素附着：除神圣伤害外暂无数据来源
- 攻击值范围：`unit_stats` 只有单值 `damage`
- 击杀奖励：暂无配置字段
- 生效中的 buff/光环列表：运行时没有统一只读端口
- 建筑攻击属性：普通建筑数据模型没有统一攻防字段
- 建筑研发、活体成长、陷阱冷却和特殊能力：运行时数据尚未统一暴露
