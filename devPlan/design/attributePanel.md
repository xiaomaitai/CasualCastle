# 属性面板（左下角）展示规则

## 1. 面板概述

- 位置：1920×1080 下左下角 x 24~456，y 837~1080；尺寸 432×243（16:9）
- 纯展示面板，无升级、出售等交互
- 点选单位或建筑时显示，点空白处隐藏
- 如果一个区域没有内容，后面的紧凑补上而不是留空
- 实现：`scripts/adapters/godot/ui/AttributePanelController.cs`，场景 `scenes/main/main_game.tscn` 的 `UI/AttributePanel`

## 2. 通用区域（单位与建筑共用）

| 区域 | 内容 | 规则 |
|------|------|------|
| 头像 | 单位立绘 / 建筑贴图 | 缺失时显示占位图 |
| 名称 | 单位中文名 / 建筑名 | — |
| 副标题 | 我方·种族·隐身中/伏击中；建筑为 我方·状态 | 状态：工作/休眠/手动暂停/已禁止组合/已摧毁 |
| 生命条 | ProgressBar + 当前/最大数字 | 替代旧"生命 X/Y"文字；实时刷新，单位和建筑共用；不显示百分比 |

## 3. 单位属性区（图标行 + 数值，悬停显示明细）

每行左侧为程序绘制的小图标，右侧为数值；区域不使用文字标题。

| 区域 | 图标 | 显示内容 | 悬停浮窗 | 数据来源 |
|------|------|----------|----------|----------|
| 抗性 | 弹回攻击的盾代表强抗性，碎裂的盾代表弱抗性 | 所有抗性中最强和最弱的一项，要求强抗性大于0，弱抗性小于0，否则不显示这半个区域 | 列出所有不为 0 的抗性 | unit_stats 暂无抗性字段，当前显示"无" |
| 攻击力 | 剑 | 平均攻击值 + 攻击类型（近战/远程·伤害类型） | 攻击数值：攻击值范围；攻击类型：该伤害类型对各类护甲不为 100% 的增伤/减伤 | damage（单值）、attack_type、damage_type、damage_matrix |
| 元素 | 魔法旋风 | 攻击类型右侧的元素 icon 行 | 图标悬停显示元素名 | 当前仅神圣伤害按规则推导神圣元素，其余元素暂无数据来源 |
| 护甲 | 盔甲 | 护甲值 + 护甲类型 | 护甲数值：护甲减伤百分比；护甲类型：受各攻击类型不为 100% 的伤害修正 | armor_value、armor_type、damage_matrix |
| 击杀奖励 | 金币 | 数值 | 无 | 暂无 |
| buff和光环效果 | 无区域图标 | 来源技能的图标，放在小圆形框里 | 每种buff的效果 | 来源技能 |

## 4. 技能区（单位）

- 技能图标行位于面板底部，悬停显示技能名与描述
- 冷却中的技能显示顺时针遮罩 + 剩余秒数

## 5. 建筑属性区

建筑不受普通buff和光环影响，有一些区别：

- 有攻击力的建筑如箭塔显示和单位相同的攻击属性
- 产出兵种与成本（不产出单位时显示"不产出单位"）
- 生产速率
- 当前生产、研发、仪式进度
- 邻接加成效果
- 建筑特殊能力（如有）

## 6. 数值规则

- 护甲减伤率 = 护甲值 ÷ (|护甲值| + 15)，浮窗按四舍五入显示百分比；负护甲显示负数（增伤）
- 攻防矩阵：增伤/减伤来自 damage_matrix，仅展示不为 100% 的倍率，正值为 +x%，负值为 -x%
- 抗性：多元素攻击按 min(各元素抗性) 结算（见 devPlan/concepts/general.md），面板只展示最强/最弱与不为 0 的列表

## 7. 数据缺口（当前显示受限于数据模型）

- 抗性数值：unit_stats 无抗性字段，抗性区显示"无"
- 攻击元素附着：仅神圣伤害类型按规则推导神圣元素，火焰/毒素/暗影/冰霜/雷电无数据来源
- 攻击值范围：unit_stats 只有单值 damage，攻击范围浮窗显示 X ~ X

## 8. 备选属性

| 属性 | 旧展示方式 | 是否保留建议 |
|------|-----------|-------------|
| 生命 | "生命 X/Y" 文本 | 已由生命条替代 |
| 视野 | "视野 N" 文本 | 可作图标行备选 |
| 攻速（攻击冷却） | "冷却 Ns" 文本 | 可作图标行备选 |
| 射程 | "射程 N" 文本 | 可作图标行备选 |
| 速度 | "速度 N" 文本 | 可作图标行备选 |
| 状态 | "状态 正常/隐身中" 文本 | 已并入副标题 |
| 护盾 | "护盾 N" 文本（有值时显示） | 可作图标行备选 |
