# 战斗系统设计文档

---

## 1. 概述

描述游戏战斗系统的核心规则与交互逻辑。

---

## 2. 建筑系统

### 2.1 建筑状态

| 状态 | 条件 | 行为 |
|------|------|------|
| 正常运行 | 生命值 > 0 且未暂停 | 正常产兵/工作 |
| 受损 | 生命值 > 0 且 < 最大生命 | 继续工作，显示受损视觉 |
| 摧毁 | 生命值 <= 0 | 停止工作，释放格子，可被穿过 |
| 暂停 | 手动暂停 | 停止工作，可恢复 |

### 2.2 产兵规则

**核心规则**：产兵采用点数累积制，进度达标后产出一个单位。

- 工作进度按生产率（`production_rate`）每秒累计，累计满该建筑对应兵种的单位成本（`unit_cost`）后产兵并清零进度
- 生产率统一为 100 点/秒，产兵耗时 = `unit_cost` / 100 秒（如成本 2000 的兵营约 20 秒产一个）
- 仅当建筑配置了产出兵种（`unit_type_id`）且该兵种成本 > 0 时启动工作；未配置或成本为 0 视为数据未完成，不产兵
- 白天产兵，夜晚停止（见 §5）

### 2.3 建筑摧毁规则

**核心规则**：建筑被摧毁后，其占用的地块恢复空闲状态，单位可穿过。

- 格子占用释放：建筑摧毁时自动释放所有占用的格子，允许其他单位通行
- 碰撞体保留：保留碰撞体用于检测敌方单位是否站在建筑上

### 2.3 建筑修复规则

**核心规则**：如果敌方单位站在被摧毁的建筑上，夜晚商店无法修复该建筑。

- 修复条件：建筑受损、非核心建筑、属于玩家、建筑上无敌方单位
- 修复成本：按缺失生命值计算（缺失生命 × 每点生命修复金币）

## 3. 单位系统

### 3.1 单位行为状态

| 状态 | 条件 | 行为 |
|------|------|------|
| 正常活动 | 存活且活跃 | 移动、追击、攻击 |
| 夜晚休眠 | 存活、处于夜晚 | 停止移动与攻击 |
| 死亡 | 生命值 <= 0 | 淡出后移除 |

### 3.2 单位与建筑交互

**核心规则**：单位忽略已摧毁的建筑，可直接穿过。

- 单位进入建筑碰撞区时，检查建筑是否已摧毁
- 仅对未摧毁的建筑锁定攻击目标
- 攻击目标被摧毁后，自动清除目标引用

### 3.3 距离概念

单位感知敌人依赖三个嵌套距离（由近到远）：

| 距离 | 含义 | 典型值（近战） | 说明 |
|------|------|--------------|------|
| **射程 `AttackRange`** | 可以造成伤害的距离 | 90 px | 边缘距离 ≤ 此值才能攻击 |
| **视野 `VisionRange`** | 单位自主"看到"敌人的距离 | 250 px | 敌人在视野内 → 交战 |
| **反击传播范围** | 受击单位呼救，友军响应的范围 | 同 `VisionRange` | 以受击单位为圆心，范围内友军集体反击 |

```
         ┌──────────────────────────────────────────┐
         │         视野 VisionRange                 │
         │   ┌──────────────────────┐               │
         │   │   射程 AttackRange    │               │
         │   │   🗡️ 可造成伤害      │               │
         │   │                      │               │
         │   └──────────────────────┘               │
         │   视野内 = 主动交战                       │
         │   视野外 = 看不见，无法主动交战             │
         └──────────────────────────────────────────┘
         
         但：被视野外的敌人攻击时 → 受击单位 + 范围内友军 → 集体反击
```

#### 目标选择规则

- 所有单位统一规则：在 `VisionRange` 视野内选择**边缘距离最近**的敌方单位为目标
- 视野外不可选为目标；目标选择每帧执行，目标死亡或离开视野后自动换选
- 特殊目标逻辑只属于特殊单位（如刺客），由用户明确提出后单独设计，不进入通用规则

### 3.4 单位行为状态机

单位的每帧行为由以下有限状态机驱动。**核心原则：找不到攻击目标时，总是回到"行军"——向敌方城堡前线推进，即摧毁敌方核心。**

```
                              ┌──────────────────────────────────────────────┐
                              │              行军 MARCHING                   │
                              │   向敌方城堡前线移动（GetDestination）          │
                              │   【默认状态 · 兜底状态】                      │
                              └────┬──────────┬──────────┬─────────────────┘
                                   │          │          │
                    敌方单位进入    │  受击（攻击者  │  AreaEntered
                    视野范围        │  在视野外）或   │  检测到敌方建筑
                    (≤VisionRange)  │  收到友军呼救   │  且无更高优先级目标
                                   │          │          │
                                   ▼          ▼          ▼
                        ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
                        │ 交战 FIGHTING │ │ 反击 RETAL.  │ │ 攻城 SIEGING │
                        │ 向敌人移动    │ │ 向攻击者移动   │ │ 攻击阻挡建筑  │
                        │ 射程内攻击    │ │ 射程内攻击    │ │ 伤害穿透城堡  │
                        └──────┬───────┘ └──────┬───────┘ └──────┬───────┘
                               │                │                │
                目标死亡/      │  攻击者进入视野  │  攻击者死亡/   │
                移出视野        │  → 升级为交战   │  移出索敌范围   │
                               │                │                │
                               ▼                │                │
                              ┌──────────────────────────────────────────────┐
                              │              行军 MARCHING                   │
                              │          （回到核心任务）                      │
                              └──────────────────────────────────────────────┘

        反击触发条件：单位 TakeDamage 时，攻击者距离 > 受击单位的 VisionRange
                  → 受击单位进入 RETALIATING
                  → BattleManager 通知受击单位 VisionRange 内的友军集体进入 RETALIATING
        注意：已在 FIGHTING 的友军不受呼救影响（交战优先级 > 反击）
        反击目标进入视野 → 升级为 FIGHTING
        反击途中撞到建筑 → SIEGING
        建筑被摧毁 且 无其他目标 → MARCHING
```

#### 状态定义

| 状态 | 含义 | 移动方式 | 攻击行为 |
|------|------|----------|----------|
| **行军 `Marching`** | 无攻击目标，执行核心任务：摧毁敌方城堡 | 流场驶向 `MoveGoal`，遇建筑绕行、贴墙滑动 | 无 |
| **交战 `Fighting`** | 敌方单位在**视野范围内**，主动迎战 | 向目标移动拉近距离；进入射程后**原地站定**（无 MoveGoal） | 进入射程后 `_attackBehavior.TryExecute()`，冷却就绪时造成伤害 |
| **反击 `Retaliating`** | 被视野外的敌人攻击，或响应友军呼救，集体反击 | 向攻击者移动拉近距离；进入射程后**原地站定**（无 MoveGoal） | 进入射程后 `_attackBehavior.TryExecute()`，冷却就绪时造成伤害 |
| **攻城 `Sieging`** | 攻击挡路的敌方建筑 | 停在建筑旁（无 MoveGoal） | 每冷却周期对建筑造成 `Damage` 点伤害，穿透至城堡 |

#### 包抄与友军避让（B5）

包抄**不是主动状态**，由流场 + 软分离自然形成：

- 接战/攻城单位进入射程后**原地站定**（无 MoveGoal），作为**静态障碍**出现在空间哈希中
- 后方的行军单位经软分离绕开站定的接战单位，像水流一样绕开交战线，从侧面包上敌方目标
- 移动方向由 `NavigationService` 统一驱动：流场方向 + 软分离 + 到达刹车 + 贴墙滑动（详见 `navigationSystem.md`）

### 3.5 特殊行动：隐身（B6）

隐身是叠加在状态机之上的**状态标记**，不新增状态：

- 进入：与敌方单位距离 > 潜行距离时自动进入（`StealthService` 每帧更新）
- 效果：敌方索敌跳过隐身单位（`TacticalQueryService`）；隐身单位索敌优先远程；移动速度 ×0.85
- 破隐：攻击（`Unit.TryAttack`）、被 AOE 伤害命中（`TakeDamage(isAoe)`）、敌方存在反隐单位
- 反隐：`unit_stats.can_detect_stealth`，当前仅轻骑兵

#### 状态转换规则

| 转换 | 触发条件 | 说明 |
|------|----------|------|
| **行军 → 交战** | 敌方单位进入 `VisionRange` | 视野内发现敌人，主动迎战 |
| **行军 → 反击** | `TakeDamage` 时攻击者在视野外，**或** 收到友军反击呼救 | 受击反击或响应友军呼救 |
| **行军 → 攻城** | `AreaEntered` 检测到敌方建筑，且无单位目标 | 建筑阻挡去路，拆障 |
| **交战 → 行军** | 目标死亡，**或** 目标移出 `VisionRange` 且无其他候选 | 威胁消失，回到核心任务 |
| **反击 → 交战** | 攻击者进入 `VisionRange` | 追上了 / 敌人靠近了，升级为交战 |
| **反击 → 行军** | 攻击者死亡，**或** 攻击者移出索敌范围 | 追丢了，放弃 |
| **反击 → 攻城** | `AreaEntered` 检测到敌方建筑 | 反击途中被建筑阻挡 |
| **攻城 → 交战** | 敌方单位进入 `VisionRange` | 单位优先级 > 建筑 |
| **攻城 → 反击** | `TakeDamage` 时攻击者在视野外，**或** 收到友军反击呼救 | 单位优先级 > 建筑 |
| **攻城 → 行军** | 建筑被摧毁，且无其他目标 | 障碍消失，继续向城堡推进 |
| **任意 → 行军** | 当前目标无效（死亡/销毁/`null`），且无其他候选目标 | **兜底规则：总是回到摧毁敌方核心** |

> **注意**：已在 FIGHTING 状态的单位收到友军反击呼救时**不切换**——交战优先级高于反击，单位不会放弃眼前的敌人去追击远处的攻击者。

#### 反击触发与传播机制

```
TakeDamage(attacker, amount):
  1. 正常扣血、受击闪烁
  2. 计算 attacker 与自己的距离
  3. 如果 距离 > VisionRange（攻击者在视野外）:
       → 自身进入 RETALIATING，目标 = attacker
       → BattleManager.PropagateRetaliation(center: self, radius: VisionRange, target: attacker)

BattleManager.PropagateRetaliation(center, radius, target):
  for each allied unit within radius of center:
      if unit is in MARCHING or SIEGING:
          unit 进入 RETALIATING，目标 = target
      // 已在 FIGHTING 的单位不切换
```

#### 状态机伪代码

```
每帧 _Process(dt):
  1. 检查存活、游戏状态、昼夜
     → 不存活 / 游戏结束 / 休眠 → return
  2. 扣减攻击冷却
  3. 确定当前状态:

     if _targetEnemy != null && _targetEnemy.IsAlive:
         dist = DistanceTo(_targetEnemy) - 双方碰撞半径
         if dist <= VisionRange:
             state = FIGHTING
         else:
             state = RETALIATING   // 视野外，但正在反击

     else if _targetBuilding != null && !_targetBuilding.IsDestroyed
           && _targetCastle != null && _targetCastle.IsAlive:
         state = SIEGING

     else:
         state = MARCHING

  4. 执行状态行为:
     FIGHTING / RETALIATING:
         if 边缘距离 <= AttackRange:
             原地站定攻击（无 MoveGoal）
         else:
             MoveGoal = target 位置（拉近距离，流场追逐）
     SIEGING:
         building.TakeDamage(Damage), 穿透至 Castle
         原地停留（无 MoveGoal）
     MARCHING:
         MoveGoal = 行军目的地

     注：移动由 NavigationService 统一驱动，后方行军单位经软分离绕开站定的接战单位，自然形成侧面包抄。
```

#### 目标优先级与兜底

```
目标优先级（从高到低）:
  1. 视野内的敌方单位     → FIGHTING（主动迎战）
  2. 反击目标（视野外）    → RETALIATING（受击反击 / 响应友军呼救）
  3. 阻挡路径的敌方建筑    → SIEGING（攻城拆障）
  4. 无目标               → MARCHING（向敌方城堡前线推进）

兜底规则:
  - 任何状态下，若当前目标消失且无新候选，立即转为 MARCHING
  - MARCHING 的目的地永远指向敌方城堡方向（GetDestination）
  - 反击与交战的本质相同（向敌人移动、射程内攻击），区别在于触发方式和优先级
  - 反击是集体行为：一个单位被视野外敌人攻击，周围友军一起反击
  - 已在交战的单位不受呼救影响（交战 > 反击）
  - 单位的最终目的始终是摧毁敌方核心，战斗只是清除障碍
```

## 4. 碰撞层设计

| 层 | 值 | 用途 |
|----|----|------|
| Layer 2 | 2 | 单位 |
| Layer 3 | 4 | 建筑 |

**单位碰撞配置**：检测单位 + 建筑
**建筑碰撞配置**：不主动检测其他对象

**单位-建筑避障（流场）**：
- 敌方**非核心**建筑（`IsCore == false`）占用的格子为阻塞格，流场自然绕行，单位贴墙滑动不穿入
- **核心建筑**（城堡）不阻塞：单位可流入核心区域并转为攻城
- 已摧毁建筑不阻塞，单位可直接穿过
- 接战/攻城单位无 MoveGoal，原地站定

**单位-单位间距（软分离）**：行军单位对邻近单位（含站定的接战单位）施加软分离，影响半径 = 双方碰撞半径和 × `SeparationRadiusMultiplier`（1.6）；接战单位原地站定成为避让障碍，后方单位绕行形成水流式侧面包抄（详见 `navigationSystem.md`）。

## 5. 昼夜阶段影响

### 5.1 白天阶段
- 出兵建筑正常产兵
- 单位正常移动、追击、攻击

### 5.2 夜晚阶段
- 所有建筑停止产兵
- 所有单位停止行动，原地休眠
- 可在商店修复受损建筑（需满足修复条件）

## 6. 关键流程

### 6.1 建筑摧毁流程

```
建筑被摧毁
    ↓
释放格子占用
    ↓
碰撞体保留（用于修复检测）
    ↓
单位检测到建筑 → 检查是否已摧毁
    ↓
已摧毁 → 忽略，继续移动
未摧毁 → 锁定攻击目标
```

### 6.2 建筑修复流程

```
夜晚商店打开
    ↓
玩家选择修复建筑
    ↓
检查：建筑受损 && 非核心建筑 && 属于玩家
    ↓
检查：建筑上无敌方单位
    ↓
扣除金币
    ↓
执行修复
```
