# 进阶系统设计 — M5（组合 + 升级）

进阶系统包含**组合**与**升级**两种建筑强化方式，由高级建筑的**入边数量**自动判定，不再存在"同类建筑双融合"（两座同类合成一座）的旧规则。概念入口见 `devPlan/concepts.md`；架构归属见 `devPlan/outline/c05ProjectArchitecture.md`。

## 统一判定规则

- 在科技树（编辑器画布）中，低级建筑向高级建筑连线：
  - 高级建筑**入边 > 1 条**（由多个低级建筑连线构成）→ **组合**
  - 高级建筑**入边 = 1 条** → **升级**
- **不存在同类建筑双融合**：旧数据中 `main_type_id = material_type_id` 的同类双融记录，全部迁移为升级关系
- 每个建筑有**唯一设定价值**，同时也是商店价格；编辑器新增/修改建筑时可直接编辑价值
- **升级费用 = 高级建筑价值 − 低级建筑价值**，自动计算，不单独配置
- **组合结果的价值按数据库设定**（不取组合物价值之和），组合本身不消耗金币

### 数据表

| 表 | 用途 | 关键字段 |
|----|------|---------|
| `combine_recipes` | 组合配方（入边 > 1） | `main_type_id`、`material_type_id`、`material_count`、`result_type_id` |
| `upgrade_recipes` | 升级配方（入边 = 1） | `source_type_id`、`result_type_id`（费用 = 价值差，无费用列） |
| `building_defs` / `tech_tree_nodes` | 建筑定义 | `value`（唯一价值 = 商店价） |

## 组合（Combine）

合成阶段（夜晚结束后、下一天白天开始前）将满足配方、且与**主体建筑**四向邻接的材料建筑，自动合并为一座强化建筑。概念入口见 `devPlan/concepts.md`；架构归属见 `devPlan/outline/c05ProjectArchitecture.md`。

---

## 时机与触发

- **仅合成阶段**：在 `GameManager` 切换到 `Combine`（夜晚结束）时，由 `CombineSystem` **自动扫描并执行**所有合法组合
- **局内条件**：`Playing` 且未暂停、未结算
- **仅玩家侧**：敌方城堡建筑不参与组合
- **无组合工具按钮**：玩家不手动点选「组合」；进入合成阶段后系统自动完成
- **禁止组合工具**：底部工具栏提供「禁止组合」按钮（与暂停、修复并列），用于标记不参与自动组合的建筑

## 基本规则

### 配方与主体

每条 `CombineRecipe` 指定：

| 字段 | 说明 |
|------|------|
| `MainTypeId` | **主体**建筑类型（组合结果落在此建筑锚点） |
| `MaterialTypeId` | 辅材建筑类型 |
| `MaterialCount` | 除主体外、须与主体四向邻接的辅材数量 |
| `ResultTypeId` | 结果建筑类型 |

**邻接判定（多建筑时）：**

- 主体 1 座，辅材 `MaterialCount` 座
- 每一座辅材须与**主体**四向相邻（与 `AdjacentSystem` 一致）
- 辅材之间**不要求**互相邻接
- 材料须匹配配方类型；组合仅用于**跨线/多来源**配方（`MainTypeId != MaterialTypeId` 或 `MaterialCount > 1`）

### 材料条件

参与组合的建筑须**同时满足**：

| 条件 | 说明 |
|------|------|
| 归属 | 玩家城堡内已放置建筑 |
| 状态 | 未摧毁、非手动暂停 |
| 类型 | 非核心建筑（不可组合城堡之心） |
| 阶数 | M5 首版仅 **0 阶 → 1 阶**，已 1 阶不可再融 |
| 禁止标记 | 未标记「禁止组合」 |
| 占据 | 未被敌军站在建筑格上（与修复规则一致） |
| 配方 | 能与主体组成某条 `CombineRecipe` 的完整材料组 |

### 占地限制（M5 首版）

- **仅支持单格建筑**（兵营、狼穴）
- 多格建筑（靶场、马厩）**暂不纳入** M5

### 组合结果

- 结果建筑落在**主体**的锚点格
- 所有辅材移除，其占格恢复空闲
- 结果建筑 **满血**（`Health = MaxHealth`），不继承材料生命比例
- 产兵进度：**清零**
- 手动暂停、禁止组合标记：**不继承**（结果建筑为默认可操作状态）
- 组合后调用 `AdjacentSystem.RefreshCastle` 刷新邻接加成

### 经济

- 组合**不消耗金币**
- 组合结果建筑的价值**按数据库设定值**，不累加输入建筑价值

## 升级（Upgrade）

升级是单入边（1 对 1）的即时强化，部落等派系的核心进阶方式。

- 花费金币将场上低级建筑**就地升级**为高级建筑，保留位置与当前血量百分比
- **随时可升**，不依赖合成阶段，无需等待昼夜切换
- 升级费用 = **高级建筑价值 − 低级建筑价值**，自动计算
- 升级后原低级建筑被替换，位置与血量百分比保留；产兵进度清零
- 升级不进入 `combine_recipes`，单独存 `upgrade_recipes`，合成阶段不触发升级

### 合成阶段自动执行顺序

```text
PhaseChanged → Combine（夜晚购买/放置/修复完成后）
  → CombineSystem.ResolveNightCombines(castle)
       循环直到无可组合组：
         扫描城堡内所有合法 (主体 + 辅材) 组
         按稳定规则选取一组（见下）→ TryFuse → 刷新邻接
  → 合成结束 → PhaseChanged → Day（下一天开始）
```

**选取规则（实现约定，避免歧义）：**

- 优先处理「主体锚点」字典序最小的一组（`AnchorGridY`，再 `AnchorGridX`）
- 同一建筑同一夜最多参与一次组合
- 一次 `TryFuse` 只消耗一条配方的一组材料

## 禁止组合

### 工具交互

- 底部「禁止组合」按钮：toggle 工具模式（与暂停 / 修复互斥，`ButtonGroup`）
- 激活后左键点击玩家侧、非核心建筑：切换该建筑的 `IsCombineProhibited`
- 右键 / Esc：退出工具
- **白天也可用**（提前标记，合成阶段生效）；与修复工具不同，不限制夜晚

### 表现

- 被禁止的建筑在格子上显示可辨识标记（如禁止图标，实现时与暂停图标并列或叠加）
- 建筑信息面板悬停时可显示「已禁止组合」

### 语义

- `IsCombineProhibited == true` 的建筑**不能**作为主体或辅材
- 取消禁止后，下一循环合成阶段扫描可正常参与组合

## 系统职责

| 模块 | 职责 |
|------|------|
| `CombineSystem` | 配方表、`FindCombinableGroups` / `TryFuse`、`ResolveNightCombines`、移除辅材与生成结果 |
| `Building` | `IsCombineProhibited` 字段及状态图标 |
| `BuildingSystem` | 强化建筑定义、`CreateBuilding`、占地与产兵属性 |
| `CombineProhibitUiController` | 禁止组合工具按钮、点击切换标记、光标 |
| `GameManager` | 合成阶段开始时调用 `CombineSystem.ResolveNightCombines` |
| `ShopSystem` | 无组合费用关联 |
| `UIManager` | 注册禁止组合工具的 `Process` / `HandleInput` |

信号建议：`CombineCompleted(Castle, Building result)`，供 UI 音效或日志。

## 边界与不做事项

| 场景 | 处理 |
|------|------|
| 白天 | 不执行组合；可标记禁止组合 |
| 材料被敌军占据 | 该建筑不参与组合 |
| 游戏中途暂停 | 合成阶段组合在暂停前已执行；禁止组合工具退出 |
| 手牌卡牌 | 手牌为**一次性放置卡**，打出后消耗，**不与场上建筑绑定**；组合不改变手牌 |
| 组合动画 | 可选：简短缩放/闪光；无动画亦可通过验收 |
| AI 组合 | M6 敌方由战报镜像复刻，不单独跑组合逻辑 |

---

## 验收标准

- [ ] 合成阶段，跨线组合（如皇家壁垒 + 皇家军府 → 圣壁）自动执行，结果落在主体锚点，辅材移除，结果**满血**
- [ ] 「禁止组合」工具可标记 / 取消标记；被标记建筑不参与自动组合
- [ ] 白天不组合；核心建筑、多格建筑、已 1 阶建筑不可误融
- [ ] 组合后邻接加成正确刷新
- [ ] 与商店 / 修复 / 手牌 / 昼夜循环输入不冲突
- [ ] 升级（单入边）不触发组合，费用 = 价值差，位置与血量百分比保留
