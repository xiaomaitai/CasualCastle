# 进阶系统设计 — M5（组合 + 升级）

进阶系统包含**组合**与**升级**两种建筑强化方式，由高级建筑的**入边数量**自动判定，不再存在"同类建筑双融合"（两座同类合成一座）的旧规则。概念入口见 `devPlan/concepts/general.md`；架构归属见 `devPlan/outline/c05ProjectArchitecture.md`。

## 统一判定规则

- 在科技树（编辑器画布）中，低级建筑向高级建筑连线：
  - 高级建筑**入边 > 1 条**（由多个低级建筑连线构成）→ **组合**
  - 高级建筑**入边 = 1 条** → **升级**
- **不存在同类建筑双融合**：旧数据中 `main_type_id = material_type_id` 的同类双融记录，全部迁移为升级关系
- 每个建筑有**唯一设定价值**，同时也是商店价格；编辑器新增/修改建筑时可直接编辑价值
- **升级费用 = 高级建筑价值 − 低级建筑价值**，自动计算，不单独配置
- **组合结果的价值按数据库设定**（不取组合物价值之和），组合本身不消耗金币

### 数据表

| 表 | 用途 | 关键字段 |
|----|------|---------|
| `combine_recipes` | 组合配方（入边 > 1） | `main_type_id`、`material_type_id`、`material_count`、`result_type_id` |
| `upgrade_recipes` | 升级配方（入边 = 1） | `source_type_id`、`result_type_id`（费用 = 价值差，无费用列） |
| `building_defs` / `tech_tree_nodes` | 建筑定义 | `value`（唯一价值 = 商店价） |

---

## 组合（Combine）

组合是**玩家手动触发**的即时强化：点击建筑后，建筑行动环提供「组合」按钮（与出售、升级并列），执行后材料建筑消失、结果建筑落在主体锚点。**不存在合成阶段，也不存在夜间自动组合**。

---

## 时机与触发

- **随时可组合**：作战与商店阶段均可；与升级、出售一致，通过**建筑行动环**触发
- **无自动执行**：进入夜晚不触发任何组合；组合完全由玩家点击建筑行动环的「组合」按钮执行
- **局内条件**：对局进行中，行动环可用（未暂停、未结算）
- **仅玩家侧**：敌方城堡建筑不参与组合
- **禁止组合工具**：底部工具栏的「禁止组合」工具保留，标记的建筑不能作为手动组合的主体或辅材

## 基本规则

### 配方与主体

每条 `CombineRecipe` 指定：

| 字段 | 说明 |
|------|------|
| `MainTypeId` | **主体**建筑类型（组合结果落在此建筑锚点） |
| `MaterialTypeId` | 辅材建筑类型 |
| `MaterialCount` | 除主体外、须与主体四向邻接的辅材数量 |
| `ResultTypeId` | 结果建筑类型 |

**邻接判定（多建筑时）：**

- 主体 1 座，辅材 `MaterialCount` 座
- 每一座辅材须与**主体**四向相邻（与 `AdjacentSystem` 一致）
- 辅材之间**不要求**互相邻接
- 材料须匹配配方类型；组合仅用于**跨线/多来源**配方（`MainTypeId != MaterialTypeId` 或 `MaterialCount > 1`）

### 材料条件

参与组合的建筑须**同时满足**：

| 条件 | 说明 |
|------|------|
| 归属 | 玩家城堡内已放置建筑 |
| 状态 | 未摧毁、非手动暂停 |
| 类型 | 非核心建筑（不可组合城堡之心） |
| 阶数 | M5 首版仅 **0 阶 → 1 阶**，已 1 阶不可再融 |
| 禁止标记 | 未标记「禁止组合」 |
| 占据 | 未被敌军站在建筑格上（与修复规则一致） |
| 配方 | 能与主体组成某条 `CombineRecipe` 的完整材料组 |

### 占地限制（M5 首版）

- **仅支持单格建筑**（兵营、狼穴）
- 多格建筑（靶场、马厩）**暂不纳入** M5

### 组合结果

- 结果建筑落在**主体**的锚点格
- 所有辅材移除，其占格恢复空闲
- 结果建筑 **满血**（`Health = MaxHealth`），不继承材料生命比例
- 产兵进度：**清零**
- 手动暂停、禁止组合标记：**不继承**（结果建筑为默认可操作状态）
- 组合后调用 `AdjacentSystem.RefreshCastle` 刷新邻接加成

### 经济

- 组合**不消耗金币**
- 组合结果建筑的价值**按数据库设定值**，不累加输入建筑价值

## 升级（Upgrade）

升级是单入边（1 对 1）的即时强化，部落等派系的核心进阶方式。

- 花费金币将场上低级建筑**就地升级**为高级建筑，保留位置与当前血量百分比
- **随时可升**，不依赖任何阶段，无需等待昼夜切换
- 升级费用 = **高级建筑价值 − 低级建筑价值**，自动计算
- 升级后原低级建筑被替换，位置与血量百分比保留；产兵进度清零
- 升级不进入 `combine_recipes`，单独存 `upgrade_recipes`

### 手动组合执行流程

```text
玩家点击建筑 → 建筑行动环显示（出售/暂停/升级/组合…）
  → 点击「组合」按钮 → CombineService.TryCombineMain(castle, 主体)
      用 FindCombinableGroupForMain 扫描以该主体为锚的合法 (主体 + 辅材) 组（按配方序第一条可行组）
      → TryCombineGroup：销毁辅材与主体 → 在主体锚点生成结果建筑 → 刷新邻接
  → 组合完成（主体与辅材节点销毁，行动环随选中失效自动关闭）
```

**选取规则（实现约定，避免歧义）：**

- 每个建筑行动环最多为一条以该建筑为主体的配方提供一个「组合」按钮
- 按钮可用性：`FindCombinableGroupForMain` 找到一组完整材料时可用，否则置灰
- 一次点击只执行一组 `CombineRecipe` 的材料组，不连锁

## 禁止组合

### 工具交互

- 底部「禁止组合」按钮：toggle 工具模式（与暂停 / 修复互斥，`ButtonGroup`）
- 激活后左键点击玩家侧、非核心建筑：切换该建筑的 `IsCombineProhibited`
- 右键 / Esc：退出工具
- **白天与夜晚均可用**；与修复工具不同，不限制阶段

### 表现

- 被禁止的建筑在格子上显示可辨识标记（禁止图标，与暂停图标并列或叠加）
- 建筑信息面板悬停时可显示「已禁止组合」

### 语义

- `IsCombineProhibited == true` 的建筑**不能**作为手动组合的主体或辅材（保护其不被材料吸收）
- 取消禁止后，该建筑可正常作为主体或辅材参与手动组合
- 组合结果建筑不继承禁止标记

## 系统职责

| 模块 | 职责 |
|------|------|
| `CombineRules` | 配方表、`FindCombinableGroupForMain`（以指定主体找可行组）、参与条件 |
| `CombineService`（ICombineUseCase） | `TryCombineMain`：执行单组手动组合（销毁辅材与主体、生成结果）；`ResolveCombines` 批量扫描保留给开发冒烟 |
| `CombineBuildingFactory` | 组合结果建筑节点 生成/销毁（绑定主体锚点、释放辅材占格） |
| `BuildingActionRingController` | 建筑行动环的「组合」按钮：可用性判定、点击触发、组合完成音效与邻接刷新 |
| `Building` | `IsCombineProhibited` 字段及状态图标 |
| `CombineProhibitUiController` | 禁止组合工具按钮、点击切换标记、光标 |
| `UIManager` | 注册禁止组合工具的 `Process` / `HandleInput`；行动环组合按钮走选中建筑流程 |

## 边界与不做事项

| 场景 | 处理 |
|------|------|
| 阶段循环 | 无合成阶段：作战 → 商店 → 作战；组合不绑定任何阶段 |
| 材料被敌军占据 | 该建筑不能作为主体或辅材 |
| 游戏中途暂停 | 行动环不可用，无法触发组合 |
| 手牌卡牌 | 手牌为**一次性放置卡**，打出后消耗，**不与场上建筑绑定**；组合不改变手牌 |
| 组合动画 | 可选：简短缩放/闪光；无动画亦可通过验收 |
| AI 组合 | 敌方由战报镜像复刻，不执行组合 |

---

## 验收标准

- [ ] 点击建筑行动环出现「组合」按钮；材料齐全时可用，点击后结果落在主体锚点，辅材移除，结果**满血**
- [ ] 材料不齐全时「组合」按钮置灰；非组合配方主体（仅升级线建筑）不显示组合按钮
- [ ] 「禁止组合」工具可标记 / 取消标记；被标记建筑不能作为手动组合的主体或辅材
- [ ] 白天与夜晚均可用手动组合；核心建筑、多格建筑、已 1 阶建筑不可误融
- [ ] 组合后邻接加成正确刷新；组合结果不继承禁止组合标记
- [ ] 与商店 / 修复 / 手牌 / 昼夜循环输入不冲突
- [ ] 升级（单入边）不触发组合，费用 = 价值差，位置与血量百分比保留
