# 开发者工具

## 开发者模式

设置面板底部"开发者模式"勾选框，开启后显示跳过阶段按钮和按键日志。

## 科技树编辑器

从标题界面"开发者工具"菜单进入。可视化编辑派系科技树：顶部按钮切换派系与跳转建筑编辑器，画布区左键拖拽调整建筑卡片位置，右键拖拽创建进阶连线，右键点击连线删除。

**库存机制**：左侧库存面板显示当前派系"库存"中**未放置**的建筑（来源 `faction_inventory` 表，语义 = 已创建但尚未放置到科技树的草稿）。把库存建筑拖到画布即放置，保存时（保存按钮/切换派系）同步从库存扣除、不再出现在库存里；把画布卡片拖回库存区域即移除并归还库存。建筑属性（名称、价值、生命、产兵间隔、商店属性等）一律在建筑编辑器维护，科技树编辑器只负责摆放位置与连线，双击无属性编辑弹窗。

**进阶连线自动分类**：保存时按高级建筑的入边数判定——入边 > 1 条落 `combine_recipes`（组合，画布白/橙），入边 = 1 条落 `upgrade_recipes`（升级，画布青色）。不存在同类建筑双融合。

保存回写 `config.db` 的 `tech_tree_nodes`，并同步 `shop_catalog` 与 `building_defs` 的放置字段（`combine_tier`/`faction_id`/`is_core`/`race_id`）；建筑数值字段（名称、价值、生命、产兵间隔、商店属性等）以 `building_defs` 为准，不被覆盖。商店卡 ID 与建筑 `type_id` 一致。关闭返回开发者工具菜单，切换派系自动保存。

## 建筑编辑器

从标题界面"开发者工具"菜单（或科技树编辑器右上角"建筑编辑器"按钮）进入。编辑当前派系的建筑定义并管理库存：

- 左侧建筑列表按派系展示（`<` `>` 切换，与科技树编辑器跳转时保留当前派系）；蓝底 = 已在库存，棕底 = 不在库存，右上角"库"角标标记
- 新建建筑：填写 TypeID（创建后不可改）与名称后保存；点选已有建筑载入属性表单
- 可编辑字段：名称、价值、最大生命、产兵间隔、兵种 ID、商店可买、费用、权重、碰撞宽/高
- "加入库存"把当前建筑加入本派系库存（`faction_inventory` 表），"从库存移除"撤销
- 数据存于 `building_defs`；`shop_available`/`gold_cost`/`shop_weight` 为该表新增列，迁移时从原 `tech_tree_nodes` 回填

## Shader 预览器

左侧编辑着色器代码，右侧实时预览，F5 编译，自动注入 time/resolution/mouse 三个 uniform。

## 参数编辑器

从标题界面"开发者工具"菜单进入。集中展示全局参数并按业务模块分组（经济、战斗、显示/像素换算），支持运行时热修改：修改输入框即时生效、无需重新编译；"重置"恢复单个参数默认值，"全部重置"恢复所有参数。

- 可编辑来源：domain 层 `GameParameters`（默认值取自 `GameRules` 常量，热修改供 `Shop`/`MatchPhaseMachine` 等消费）、adapter 层 `GameCoordinatesAdapter.PixelsPerCell` 与 `SfxPolicy`
- 当前参数：每局初始金币、修理每点生命花费、战斗阶段时长、战斗开始等待、每格像素、音效限流 4 项
- 持久化：值按业务分别存在 `config.db` 的业务配置表（`economy_config`/`battle_config`/`display_config`/`sound_config`，结构为 key/value），编辑器修改/重置即时写回对应表，核心启动（`CompositionRoot.Build`）从各表读入静态参数；不为编辑器专门建表

## 按键日志

开发模式下打印所有按键的 Keycode、Physical、Unicode、修饰键到控制台。
