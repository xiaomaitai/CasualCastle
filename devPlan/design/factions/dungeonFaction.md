# 地下城派系设计

> "地下城"是游戏性派系分类。地下城的核心是魔王宝座——魔王在城堡附近巡逻防守，其等级决定整个派系的科技上限。魔王通过杀敌获取经验升级，每升一级习得一个新技能。技能路线决定流派方向：强化自身战斗、强化陷阱防御、或强化部队生产。

---

## 1. 派系核心：魔王宝座

### 1.1 魔王

魔王是地下城的派系中枢，一座位于城堡后方的特殊建筑**魔王宝座**中驻守。魔王的行为：

- **防守模式**：魔王在宝座周围一定范围内巡逻，自动攻击进入范围的敌方单位
- **不会主动进攻**：魔王不会离开城堡区域，不会推向敌方战线（除非习得特定技能）
- **魔王死亡 = 游戏失败**：魔王是地下城的王，被击杀则本局直接失败（习得复活技能后除外）

### 1.2 魔王等级 = 科技上限

魔王的等级决定整个派系可建造的建筑 Tier 上限：

| 魔王等级 | 解锁 Tier | 备注 |
|---------|----------|------|
| Lv1 | T1 | 初始状态 |
| Lv3 | T2 | |
| Lv5 | T3 | |
| Lv7 | T4 | |
| Lv10 | T5 | 满级 |

魔王无法用金币直接升级——必须通过获取经验值来提升等级。这意味着地下城的科技速度不依赖金币经济，而依赖战斗参与度。

### 1.3 经验获取

| 来源 | 效率 | 说明 |
|------|------|------|
| 己方部队击杀 | 低 | 所有地下城部队的击杀都计入魔王经验，但转化率很低 |
| 魔王自身击杀 | 中 | 魔王在防守范围内击杀入侵者获得较多经验 |
| 经验魔晶 | 高 | 可购买或生产的消耗品，使用后直接注入大量经验 |

经验获取的慢速设计意味着：**纯防守不出兵则等级停滞**。对手消极防守时，己方部队不断进攻送死也能为魔王提供经验——每个阵亡的士兵都在为魔王贡献力量。

### 1.4 技能系统

魔王每升一级获得 1 个技能点，可从三个技能树中选择一个技能学习。技能分为三系，分别对应三个流派：

- **战斗系**（红色）：增强魔王自身战斗力
- **防御系**（蓝色）：解锁陷阱与防御建筑能力
- **统率系**（绿色）：提升部队生产效率与单位属性

各系技能有层级要求——高级技能需要该系已投入一定点数。

## 2. 流派总览

| 流派 | 核心思路 | 魔王技能倾向 | 招牌机制 |
|------|---------|-------------|----------|
| 魔王战斗流 | 魔王亲征，以一当百 | 全战斗系 | T5 后魔王主动出击 + 死亡复活 |
| 陷阱流 | 以守为攻，诱敌深入 | 全防御系 | 陷阱网络 + 宝箱诱饵 |
| 兵力流 | 魔王为将，部队为兵 | 全统率系 | 产兵加速 + 部队全属性光环 |

---

## 3. 流派一：魔王战斗流 — 御驾亲征，不死之王

### 3.1 流派特色

魔王战斗流将全部技能点投入战斗系。魔王从防守型 Boss 逐步成长为可主动出击的终极战斗单位。

**技能线：**

| 等级 | 技能 | 效果 |
|------|------|------|
| Lv1 | 魔焰斩 | 魔王普攻变为范围挥砍 |
| Lv2 | 暗影护甲 | 魔王获得额外护甲值 |
| Lv3 | 恐惧光环 | 周围敌方单位攻击力 -10% |
| Lv4 | 生命汲取 | 魔王攻击回复造成伤害的 20% |
| Lv5 | 地狱火 | 主动技能：对目标区域造成大量伤害，冷却 30s |
| Lv6 | 不灭之躯 | 魔王最大生命值 +50% |
| Lv7 | 魔能爆发 | 魔王低于 30% HP 时攻击力翻倍 |
| Lv8 | 召唤魔卫 | 每 20s 自动召唤两只恶魔卫士护卫魔王 |
| Lv9 | 毁灭风暴 | 主动技能：大范围持续伤害，冷却 45s |
| Lv10 | 魔王亲征 | 魔王可主动进攻敌方，死亡后在宝座复活（冷却 90s） |

最终形态：T5 建筑**征服王座**建成后，魔王解锁全部战斗潜能——主动进攻 + 死亡复活。即使魔王在敌方半场被击杀，也会在一分半后在宝座重生，而不是直接输掉游戏。

### 3.2 核心建筑

| 层 | 建筑 | 定位 |
|----|------|------|
| T1 | 恶魔之门 | 产出小恶魔（近战炮灰） |
| T2 | 地狱裂隙 | 产出地狱犬（快速近战） |
| T3 | 深渊祭坛 | 产出深渊恶魔（重装前排） |
| T4 | 毁灭之门 | 产出毁灭守卫（范围伤害近战） |
| T5 | 征服王座 | 解锁魔王亲征 + 复活能力 |

魔王战斗流建筑以产出近战恶魔为主——这些部队既是战斗力量，也是魔王获取经验的来源（部队击杀计入魔王经验）。

## 4. 流派二：陷阱流 — 请君入瓮，步步杀机

### 4.1 流派特色

陷阱流将魔王技能点投入防御系，将己方半场变为死亡迷宫。核心思路：**不靠部队正面决战，而是用陷阱网络消耗和歼灭来犯之敌**。

**技能线：**

| 等级 | 技能 | 效果 |
|------|------|------|
| Lv1 | 尖刺陷阱 | 解锁尖刺陷阱建筑（地面铺设，经过时触发伤害） |
| Lv2 | 陷阱大师 | 陷阱伤害 +30% |
| Lv3 | 毒气陷阱 | 解锁毒气陷阱（范围持续毒伤） |
| Lv4 | 宝箱诱饵 | 解锁宝箱建筑（吸引敌方单位靠近后爆炸） |
| Lv5 | 连携触发 | 一个陷阱触发时，相邻陷阱同时触发 |
| Lv6 | 火焰陷阱 | 解锁火焰陷阱（高伤害 + 点燃地面） |
| Lv7 | 陷阱回收 | 触发后的陷阱 20s 后自动重置 |
| Lv8 | 传送陷阱 | 解锁传送陷阱（将触发者传送回敌方半场起点） |
| Lv9 | 死亡迷宫 | 场上陷阱数量上限翻倍 |
| Lv10 | 王座堡垒 | 魔王宝座周围自动生成不可摧毁的尖刺陷阱阵 |

### 4.2 建筑体系

陷阱流有两种建筑角色：陷阱建筑（一次性建造，触发后进入冷却或消耗）和支援建筑（生产魔晶、降低陷阱冷却）。

**陷阱建筑（建造在己方半场格子上）：**

| 陷阱 | 解锁 | 效果 |
|------|------|------|
| 尖刺陷阱 | Lv1 | 触发者受到穿刺伤害 |
| 毒气陷阱 | Lv3 | 触发后释放毒云，范围持续伤害 5s |
| 宝箱 | Lv4 | 吸引范围内敌方单位靠近，3s 后爆炸 |
| 火焰陷阱 | Lv6 | 高伤害 + 地面点燃 3s |
| 传送陷阱 | Lv8 | 将触发者传送回敌方半场起点 |

**支援建筑：**

| 建筑 | 定位 |
|------|------|
| 魔晶矿井 | 持续生产经验魔晶（供魔王升级） |
| 陷阱工坊 | 降低陷阱冷却时间 |
| 深渊之眼 | 提供大范围视野，让陷阱提前感知来敌 |

陷阱流不依赖大量部队——少量用于试探和勾引即可。主力是密布己方半场的陷阱网络。

## 5. 流派三：兵力流 — 万魔出征，魔王为将

### 5.1 流派特色

兵力流将魔王技能点全部投入统率系。魔王不亲自战斗，而是作为全军的指挥官——学习增强部队生产和单位属性的光环技能。魔王等级越高，部队越强、产出越快。

**技能线：**

| 等级 | 技能 | 效果 |
|------|------|------|
| Lv1 | 督军号令 | 所有己方部队产兵间隔 -10% |
| Lv2 | 武器强化 | 所有己方部队攻击力 +10% |
| Lv3 | 护甲锻造 | 所有己方部队护甲值 +15% |
| Lv4 | 急行军 | 所有己方部队移动速度 +12% |
| Lv5 | 精锐训练 | 新产出部队初始获得一层护盾 |
| Lv6 | 战地医疗 | 己方部队在己方半场缓慢回血 |
| Lv7 | 军势 | 场上己方部队数量超过 20 时，全员 +20% 攻击 |
| Lv8 | 死亡税 | 己方部队死亡时返还 30% 金币 |
| Lv9 | 恶魔狂化 | 主动技能：全场己方部队 10s 内攻击速度 +50%，冷却 60s |
| Lv10 | 万魔殿 | 解锁 T5 建筑万魔殿，可同时产出两种不同兵种 |

### 5.2 核心建筑

| 层 | 建筑 | 产出 | 定位 |
|----|------|------|------|
| T1 | 恶魔之门 | 小恶魔 | 炮灰前排 |
| T1 | 魅魔之巢 | 魅魔 | 远程暗影伤害，魅惑（短暂策反敌方单位） |
| T2 | 地狱裂隙 | 地狱犬 | 快速近战 |
| T2 | 邪眼之塔 | 邪眼 | 远程激光持续伤害 |
| T3 | 深渊祭坛 | 深渊恶魔 | 重装前排 |
| T3 | 恶魔学者之塔 | 恶魔学者 | 后排 Buff 施法者（提升周围友军伤害） |
| T4 | 毁灭之门 | 毁灭守卫 | 范围近战 |
| T5 | 万魔殿 | 同时产出地狱犬 + 毁灭守卫 | 双倍产能 |

兵力流的建筑线比其他流派更丰富——因为魔王不亲自战斗，必须用更多样的兵种组合弥补单体战力的缺失。

## 6. 流派机制对比

| | 魔王战斗流 | 陷阱流 | 兵力流 |
|---|---|---|---|
| 魔王角色 | 终极战斗单位 | 防御技能提供者 | 全军指挥官 |
| 核心机制 | 魔王亲征 + 死亡复活 | 陷阱网络 + 宝箱诱饵 | 全属性光环 + 产能加速 |
| 强度曲线 | 前期魔王防守→中后期魔王出击 | 前期布陷阱→中期陷阱升级→后期不可穿越 | 前期产兵慢→后期人海碾压 |
| 布阵原则 | 魔王宝座居后，建筑围绕 | 半场铺设陷阱网格 | 建筑线均匀分布，最大化产兵 |
| 崩盘点 | 魔王被集火秒杀（复活冷却中） | 陷阱被远程或飞行单位绕过；陷阱预算耗尽 | 兵种单体弱，被 AOE 清场 |
| 终局上限 | T5 征服王座 + Lv10 魔王 | 死亡迷宫 + 王座堡垒 | T5 万魔殿 + Lv10 全军光环 |

## 7. 经验魔晶

经验魔晶是地下城特有的经济资源：

| 来源 | 方式 |
|------|------|
| 商店购买 | 花费金币直接购买（夜晚商店固定选项） |
| 魔晶矿井 | 陷阱流建筑，持续自动产出 |
| 击杀 Boss 单位 | 敌方 T3 及以上单位被击杀时掉落小型魔晶 |

使用魔晶后立即为魔王注入经验，是加速魔王升级的主要手段。兵力流依赖魔晶来快速提升魔王等级以解锁更强的统率光环；陷阱流则大多自产魔晶；魔王战斗流需要在魔晶和装备之间平衡金币支出。

## 8. 伤害矩阵

地下城的伤害类型与护甲类型：

| 伤害类型 | 来源 |
|---------|------|
| 挥砍 | 小恶魔、深渊恶魔 |
| 穿刺 | 尖刺陷阱、邪眼 |
| 暗影 | 魅魔、魔王（魔焰） |
| 火焰 | 地狱犬、火焰陷阱、地狱火 |

部队护甲多为 Light（小恶魔、魅魔）或 Heavy（深渊恶魔、毁灭守卫）。魔王自身为 Fortified。
