# 部落派系设计

> "部落"是游戏性派系分类。部落由兽人、哥布林、半人马、半人鹿、蜥蜴人等崇尚自由、蔑视文明的荒野诸族构成。部落的核心是**空地邻接**与**种族协同**——建筑不依赖彼此抱团，而是从周围的开阔空间中获得力量；每个部落种族拥有独一无二的种族特长（部分为荒野光环），不同种族的单位在战场上互相配合、取长补短（详见第 5 章荒野盟约）。

---

## 1. 派系核心：自由与荒野

部落是一个**速攻派系**。它的设计回答了一个问题：如果不需要买地、不需要等组合、不需要精心规划建筑邻接——直接冲脸会怎样？

答案是前期极强，后期靠运营。

部落建筑**无需购买地皮**即可放置。开局就能在城堡前方空地直接拍下第一座建筑开始产兵，而其他派系还在攒钱买第一块地。建筑不享受邻接建筑加成，取而代之的是**邻接空地加成**——周围每有一块空地，产兵速度就快一分。

前期城堡周围大片空地，每座建筑都能吃到满额加成，产兵速度碾压其他派系。随着要塞逐渐填满，内部建筑被包围、失去空地加成，只剩外围建筑还能继续高效运转。后期考验玩家的布阵远见：**最核心的建筑是否留在了朝外的位置上**。

---

## 2. 公共特性

- **日间派系**：所有单位白天活跃，夜晚休眠
- **建筑占地**：除地洞为单格外，其余全部 2×2
- **自由建造**：无需事先购买地皮，建筑可直接放置在任何己方战场格子上
- **邻接规则**：四向邻接。**邻接空地、同族建筑或地洞**获得加成，邻接异族建筑或城堡无加成
- **升级规则**：T1 建筑可花费金币**就地升级**为同族 T2（消耗 T1，原地替换），无需等待任何阶段，无需两两组合。升级可随时进行；**部落建筑只能升级到不高于部落大厅等级的目标等级**
- **地洞与核心**：地洞为单格辅助建筑，每个地洞使部落邻接加成提升 1%；部落大厅（核心建筑）升级需要足够数量的地洞（见 3.4）
- **无组合系统**：部落不通过"两座合成一座"来进阶，而是直接升级单座建筑。不用的低级建筑也可以继续保留产兵

## 3. 空地邻接系统

### 3.1 规则

每座部落建筑检查其四向邻接格子：

| 邻接格状态 | 效果 |
|-----------|------|
| 空地（无建筑） | 产兵间隔 **-5%** |
| 同族建筑（如兽人邻接兽人） | 产兵间隔 **-5%** |
| 地洞 | 产兵间隔 **-5%**（同时使每格加成再提升 1%） |
| 异族建筑 / 城堡 | 无加成 |

加成可叠加。一座建筑最多有 4 个加成邻接（四向全空），基础每格 **-5%**。场上每个地洞使每格加成提升 **1%**：0 个地洞时满加成 **-20%**，1 个地洞 **-24%**，2 个地洞 **-28%**，以此类推。

### 3.2 战术含义

```
前期（空地充足）：                后期（要塞拥挤）：
┌──┬──┬──┬──┐                   ┌──┬──┬──┬──┐
│  │空│  │  │                   │堡│建│建│建│
├──┼──┼──┼──┤                   ├──┼──┼──┼──┤
│空│建│空│  │                   │建│建│建│建│
├──┼──┼──┼──┤                   ├──┼──┼──┼──┤
│  │空│  │  │                   │建│建│建│建│
├──┼──┼──┼──┤                   ├──┼──┼──┼──┤
│  │  │  │  │                   │空│空│空│空│ ← 外围
└──┴──┴──┴──┘                   └──┴──┴──┴──┘
单建筑 4 空地 → -20% 产速        内圈 0 加成 → 无加成
								外圈 1~3 空地 → 部分加成
```

- **前期**：城堡周围全是空地，每座新建筑都享受高额产速加成。迅速铺开多个种族建筑，空地邻接 + 荒野盟约双重加持下形成兵力洪流
- **中期**：要塞开始填充，内部建筑逐渐失去空地加成，但**同族建筑聚团依然保持加成**。玩家面临选择——继续铺同族聚团吃加成，还是用异族/地洞分割地块
- **后期**：同族聚团与外圈空地都能提供加成；异族建筑会切断邻接加成，用地洞分割不同种族地块可避免加成损失

### 3.3 与其他派系邻接机制的对比

| | 联盟（王国军） | 部落 |
|---|---|---|
| 加成来源 | 邻接**同类型建筑** | 邻接**空地/同族/地洞** |
| 布阵逻辑 | 同类型聚团 | 同族聚团、异族用地洞分隔 |
| 前期效率 | 低（需要先凑同类型） | 高（空地到处都是） |
| 后期效率 | 高（建筑抱团加成稳定） | 同族聚团稳定，异族需分隔 |
| 核心矛盾 | 摆位 vs 组合时机 | 扩张 vs 核心等级/地洞门槛 |

### 3.4 地洞与部落大厅（核心）

**地洞**：部落的**单格**辅助建筑，商店 2g 购买。地洞不产兵，也不破坏其他建筑的邻接加成——它占用的邻接格仍按加成格计算，因此是**分割不同种族地块**的理想选择。场上每个存活地洞使部落邻接加成提升 **1%**（基础每格 5%）。

**部落大厅（部落核心）**：开局自动放置，等级 1，可花费金币逐级升级到 5 级。升级费用 = 高级价值 − 低级价值，且要求场上地洞数量达标：

| 升级 | 地洞要求 |
|------|---------|
| 1 级 → 2 级 | 1 |
| 2 级 → 3 级 | 3 |
| 3 级 → 4 级 | 10 |
| 4 级 → 5 级 | 30 |

**核心等级门槛**：部落建筑只能升级到**不高于部落大厅等级**的目标等级。例如 1 级核心下不能把兽人营地升级为兽人要塞（2 级建筑），必须先升级核心。

部落大厅各等级生命/价值为首版占位：1~5 级依次 800/1000/1200/1400/1600 HP，价值 0/20/60/150/300。

## 4. 五种族与建筑线

### 4.1 种族总览

| 种族 | 建筑 T1 | 建筑 T2 | 角色 | 弱点 |
|------|---------|---------|------|------|
| 兽人 | 兽人营地 | 兽人要塞 | 前排肉盾 + 受击狂怒爆发 | 缓慢，被远程风筝 |
| 哥布林 | 哥布林窝棚 | 哥布林工坊 | 廉价远程 + 数量碾压 | 极脆，被 AOE 清场 |
| 半人马 | 半人马营帐 | 半人马战阵 | 高速冲击 + 游击 | 身板偏脆 |
| 半人鹿 | 半人鹿圣林 | 半人鹿古树 | 治疗 + 护甲光环 | 几乎无伤害输出 |
| 蜥蜴人 | 蜥蜴人巢穴 | 蜥蜴人猎场 | 伏击 + 切后排 | 正面接战偏弱 |

五族各有短板，无法单种族制胜。兽人缺机动、哥布林缺硬度、半人马缺续航、半人鹿缺输出、蜥蜴人缺正面。**任何单一种族的单位都会被对手轻易针对——部落必须混编。**

### 4.2 兽人 — 狂怒之血

部落的基石前排。兽人战士缓慢但坚挺，一旦受击便进入狂怒状态，爆发出远超常态的战斗力——持续交战的兽人会一直处于狂怒之中，越打越危险。

**种族特长 — 狂怒**：受到伤害后进入狂怒状态并永久保持，获得强大的战斗加成。狂怒只对兽人种族生效（skill_defs `stat_modifier` 受击触发 + `race=Orc` 校验），且只强化自身，不提供光环。

**技能**：猎手/潜伏者带伏击（脱离战斗 2 秒后首次攻击伤害 +100% / +150%）+ 猎手印记光环；潜伏者额外可侦测隐身单位。

## 5. 荒野盟约（种族协同）

### 5.1 规则

兽人不参与荒野盟约：其种族特长为受击狂怒（见 4.2），只强化自身，不提供光环。其余每个部落种族拥有一个基于自身种族的**荒野光环**，持续为周围（半径约 150 游戏单位）所有友方部落单位提供增益。不同种族的光环提供**不同类型的增益**，多种族的光环效果**累加生效**。同一种族的光环不叠加——两个哥布林站在一起，依然只提供一份蜂群协调。

| 种族 | 光环名称 | 效果（对周围友方部落单位） | 弥补的短板 |
|------|---------|--------------------------|-----------|
| 哥布林 | 蜂群协调 | +12% 攻击速度 | 弥补重装单位攻速缓慢 |
| 半人马 | 疾风之蹄 | +10% 移动速度 | 弥补兽人等重型单位腿短 |
| 半人鹿 | 荒野复苏 | 每秒恢复 0.8% 最大生命值 | 弥补哥布林等脆皮缺乏续航 |
| 蜥蜴人 | 猎手印记 | 对生命值低于 30% 的敌人伤害 +20% | 弥补前排收割能力不足 |

**关键约束**：不同种族光环可叠加（4 种族齐聚 → 享受全部 4 种增益），同一种族光环不叠加（10 个哥布林依然只提供一份蜂群协调）。

半人鹿古树（T2）额外提供古树护甲光环（护甲 +1），与荒野复苏同属半人鹿光环，同样遵循同族不叠加规则。

### 5.2 战术含义：取长补短

荒野盟约的本质是**每个种族为其他种族提供自己擅长的东西**。兽人曾是攻击力光环的提供者，重做后改为受击狂怒自我强化——不再给友军光环，兽人线必须与其他光环种族混编才能补齐输出与机动。哥布林给了攻速但一碰就碎——半人鹿给了回血。蜥蜴人给了收割但正面不足——半人马给了速度。

```
纯兽人冲锋（无光环）：           五族混编（全光环叠加）：
兽 兽 兽 兽                       兽 人 蜥 哥
兽 兽 兽 兽                       马 鹿 兽 人
	↓                                  ↓
仅自身受击狂怒                    4 种族 → 攻击速度 +12%
被风筝至死                              → 攻击速度 +12%
									   → 移动速度 +10%
									   → 每秒回血 0.8%
									   → 低血量斩杀 +20%
								  兽人抗线（受击狂怒）、半人马包抄、哥布林远程、
								  半人鹿治疗、蜥蜴人补刀收割
```

光环互补示例：

| 组合 | 发生了什么 |
|------|-----------|
| 兽人 + 半人马 | 兽人获得移速（追上敌人）并靠受击狂怒爆发，半人马提供机动支援 |
| 哥布林 + 半人鹿 | 哥布林获得续航（不再一碰就碎），半人鹿获得攻速（治疗频率间接提升） |
| 蜥蜴人 + 兽人 | 蜥蜴人获得兽人抗线掩护，兽人获得斩杀（不再被残血敌人溜走） |
| 五族齐聚 | 兽人靠受击狂怒爆发，其余单位享受 4 种光环叠加——攻速、移速、回血、斩杀 |

- **单种族 = 零光环**：纯兽人仅靠受击狂怒，慢且无光环支援，容易被风筝。纯哥布林攻速快但没续航。任何单种族都有明显短板可被针对
- **2~3 种族混编 = 互相补短**：常规运营下维持 2~3 种种族在前线，光环开始互相覆盖弱点。兽人+半人马让兽人能追上人；哥布林+半人鹿让哥布林群撑过 AOE
- **5 种族满编 = 终极形态**：4 种光环叠加（兽人不提供光环）。每个单位都是高攻速、高移速、持续回血、低血量斩杀的全面战士，兽人额外靠受击狂怒爆发。代价是五条建筑线对经济和布阵的双重压榨

### 5.3 崩盘方式

- **斩杀半人鹿**：荒野复苏是部落唯一的群体续航来源。半人鹿一死，回血光环消失，单位被慢慢磨光
- **AOE 清哥布林**：哥布林群是蜂群协调光环的载体。一个范围技能清光哥布林后全军攻速骤降，输出断崖式下跌
- **逐个击破**：分散的部落单位各自只携带单一光环（兽人无光环，仅靠受击狂怒），无法互补短板——落单的兽人被风筝、落单的哥布林被秒
- **拆散混编阵型**：用控制或地形将不同种族分隔开，光环覆盖出现真空区。前线兽人脱离半人鹿回血范围后迅速崩溃
- **击杀核心种族**：每个种族的光环是独一无二的。如果对手优先清掉你的半人马（移速）或蜥蜴人（斩杀），对应的增益永久消失——需要等新单位从城堡走到前线

## 6. 战术方向

部落不设固定流派。玩家通过**选择重点发展的种族**自然形成战术方向。三种常见配置：

### 6.1 突击战团（兽人 + 半人马）

兽人正面抗线、半人马侧翼包抄。最直接的速攻打法。

- 开局优先下兽人营地和半人马营帐
- 兽人战士顶住前线（受击触发狂怒爆发），半人马猎手从侧面高速冲击后排（提供疾风之蹄，让兽人能跟上节奏）
- 兽人靠受击狂怒爆发，半人马提供移速光环，突击小队兼具伤害和机动
- 弱点：缺乏治疗续航，打一波流。如果第一波没冲下来，没有半人鹿回血光环的单位会逐渐被磨光

### 6.2 阴影猎群（哥布林 + 蜥蜴人）

哥布林远程压阵、蜥蜴人伏击切排。骚扰和控制型打法。

- 哥布林窝棚产速极快，迅速形成远程火力群（提供蜂群协调光环，全军攻速拉满）
- 蜥蜴人猎手趁敌方注意力被哥布林吸引时潜伏到后排（提供猎手印记，残血收割）
- 双光环互补：哥布林+攻速、蜥蜴人+斩杀，集火秒杀能力极强
- 弱点：极脆。兽人不再提供攻击力光环，缺乏狂怒爆发时秒杀阈值不足、无半人鹿回血光环续航为零。被敌方重骑或 AOE 突破前排后迅速崩溃

### 6.3 荒野之环（半人鹿 + 五族均衡）

以半人鹿为核心，五族雨露均沾。最慢热但最持久。

- 半人鹿德鲁伊提供回血光环（荒野复苏），兽人顶前排靠受击狂怒自我强化，哥布林远程输出提供攻速光环（蜂群协调）
- 半人马（疾风之蹄）和蜥蜴人（猎手印记）机动支援
- 全部种族在前线交汇 → 4 重光环覆盖（兽人无光环） → 每支单位同时享受攻速、移速、回血、斩杀，兽人靠受击狂怒爆发
- 弱点：启动慢。五条建筑线需要大量金币和布阵空间，前期空地虽多但金币有限，容易被速攻压制。一旦成型几乎无法正面击穿

## 7. 伤害矩阵

部落以物理伤害为主，半人鹿引入少量自然魔法伤害。

| 单位 | 伤害类型 | 护甲类型 |
|------|---------|---------|
| 兽人战士 / 狂战士 | 钝击 | Heavy |
| 哥布林投石手 / 爆破兵 | 穿刺 | Light |
| 半人马猎手 / 掠袭者 | 劈砍 | Medium |
| 半人鹿德鲁伊 / 大德鲁伊 | 自然（魔法变体） | Light |
| 蜥蜴人猎手 / 潜伏者 | 穿刺 | Medium |

部落伤害类型覆盖全面（钝击、劈砍、穿刺、自然），但缺乏真正的魔法爆发。护甲以 Light/Medium 为主，仅兽人是 Heavy——整体偏脆。

## 8. 商店

部落建筑全部可通过商店购买。T2 通过升级已有 T1 获得（不直接在商店出售 T2）。

| 建筑 | 费用 | 权重 | 解锁条件 |
|------|------|------|---------|
| 兽人营地 | 3g | 12 | 开局 |
| 地洞 | 2g | 10 | 开局 |
| 哥布林窝棚 | 2g | 14 | 开局 |
| 半人马营帐 | 4g | 10 | 开局 |
| 半人鹿圣林 | 3g | 10 | 开局 |
| 蜥蜴人巢穴 | 3g | 10 | 开局 |

**升级费用**（将场上已有 T1 升级为同族 T2）：费用 = **T2 价值 − T1 价值**，自动计算，不单独配置。

| 升级 | 价值 | 升级费 |
|------|------|--------|
| 兽人营地 → 兽人要塞 | 3g → 7g | 4g |
| 哥布林窝棚 → 哥布林工坊 | 2g → 5g | 3g |
| 半人马营帐 → 半人马战阵 | 4g → 9g | 5g |
| 半人鹿圣林 → 半人鹿古树 | 3g → 7g | 4g |
| 蜥蜴人巢穴 → 蜥蜴人猎场 | 3g → 7g | 4g |

升级可随时进行。升级后原 T1 建筑被替换为 T2，保留位置和当前血量百分比。

T2 建筑不进入商店卡池——只能通过升级已有 T1 获得。这意味着部落每拥有一座 T2，就少一座 T1 的种族来源。升级太多同族建筑 → 该族 T1 数量减少 → 该族产能下降。升多少、何时升，是部落中期核心决策。
