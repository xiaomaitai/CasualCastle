# RTS 推开系统

## 原则

- 单位之间：不用物理碰撞，每帧距离判定推开
- 单位-建筑：保留 Area2D 碰撞信号（AreaEntered → 攻城），加上推开防止重叠
- NavigationObstacle2D：删除，建筑用推开代替导航避障

## 单位-单位

BattleManager 每帧对所有同方单位对：`dist < radius_a + radius_b + 4` → 沿连线推开差额。

- 推开仅作用于**双方均未接战**（行军）的单位对；接战/攻城单位原地站定，不推开别人也不被推开
- 后方行军单位经 RVO 避让绕开站定的接战单位，形成水流式侧面包抄

## 单位-建筑

1. 推开：敌方**非核心**建筑（`IsCore == false`），仅对**行军**单位，单位中心到建筑碰撞矩形的距离 < 单位半径 → 推出（目标间距 = 单位半径 + 4）
2. **核心建筑**（城堡）不推开：单位可进入核心区域，攻城以「单位中心进入建筑矩形」触发
3. 已摧毁建筑不推开，单位可直接穿过
4. 接战/攻城单位不被建筑推开（原地站定）

## 移除项

- Unit 的 CollisionShape2D
- Building 的 NavigationObstacle2D
