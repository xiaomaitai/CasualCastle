## B3 大战场与无缝纹理（已完成）

目标：战场尺寸**大于屏幕**——屏幕只显示部分战场，可拖动查看不同位置。

实现说明：

- 战场尺寸定为 3840×2160（2 倍设计分辨率），由 `BattlefieldMetrics` 统一维护
- 摄像机边界同步为 3840×2160，初始视角对准玩家城堡，中键拖拽平移 + 滚轮缩放
- 寻路区域（NavigationRegion2D）同步扩为 3840×2160
- 底纹为程序化生成的无缝纹理（草地/泥地/石板），着色器按噪声混合，任意尺寸平铺无接缝
- 装饰层（草丛、石子）用两个 MultiMeshInstance2D 随机散布，无碰撞
- 玩家/敌方城堡移至 (150, 1210) / (2890, 1210)，交战区位于战场中部

验收项：

- [x] 战场远大于一屏，屏幕只显示部分区域
- [x] 拖拽可查看战场任意位置，摄像机不越界
- [x] 底纹平铺无可见接缝
- [x] 装饰层随机散布且不影响寻路/碰撞

## B5 单位 AI 优化

目标：平滑寻路绕障碍、目标选择优化、包抄与避让友军，行为状态机化。

细化步骤：

1. 单位移动接入 NavigationAgent2D，绕开建筑与障碍
2. 目标选择：优先攻击射程内最近敌人；远程单位优先攻击敌方远程单位
3. 包抄行为：目标正在与友军交战且自身不在目标攻击范围内时，导航到目标侧后方（与友军夹角 > 60°）
4. 移动时与友军保持最小间距，避免堆叠
5. 状态机：行军 / 索敌 / 接战 / 包抄

验收项：

- [ ] 单位能绕开建筑到达目标
- [ ] 远程单位优先攻击敌方远程
- [ ] 包抄行为生效
- [ ] 友军不再重叠堆叠

## B6 特殊行动

目标：刺客隐身渗透（首个特殊行动）。

细化步骤：

1. 隐身状态：离敌方单位一定距离时自动进入隐身，敌方无法将其选为攻击目标
2. 隐身期间穿过敌方战线，直袭后排远程单位
3. 破隐规则：攻击时破隐；被 AOE 伤害命中时破隐；敌方有反隐单位时无法隐身
4. 隐身期间移动速度略微降低

验收项：

- [ ] 刺客隐身时不会被敌方选为目标
- [ ] 攻击 / AOE / 反隐三种破隐规则全部生效
- [ ] 隐身期间有减速效果
