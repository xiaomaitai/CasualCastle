## B3 大战场与无缝纹理（已完成）

目标：战场尺寸**大于屏幕**——屏幕只显示部分战场，可拖动查看不同位置。

实现说明：

- 战场尺寸定为 3840×2160（2 倍设计分辨率），由 `BattlefieldMetrics` 统一维护
- 摄像机边界同步为 3840×2160，初始视角对准玩家城堡，中键拖拽平移（速度可在设置调整）+ 窗口边缘自动滚动 + 滚轮缩放
- 寻路区域（NavigationRegion2D）同步扩为 3840×2160
- 底纹为程序化生成的无缝纹理（草地/泥地/石板），着色器按噪声混合，任意尺寸平铺无接缝
- 装饰层（草丛、石子）用两个 MultiMeshInstance2D 随机散布，无碰撞
- 玩家/敌方城堡移至 (150, 1210) / (2890, 1210)，交战区位于战场中部

验收项：

- [x] 拖拽可查看战场任意位置，摄像机不越界

## B5 单位 AI 优化

目标：平滑寻路绕障碍、目标选择优化、包抄与避让友军，行为状态机化。

实现说明：

- 寻路：单位移动已接入 NavigationAgent2D；敌方非核心建筑仅推开行军单位（中心压线即推出至「半径 + 4」间距），实现绕开建筑滑行前进；核心城堡不推开，保持攻城可触发
- 目标选择：统一规则为视野内取边缘距离最近的敌方单位；特殊目标逻辑只属于用户明确提出的特殊单位（如刺客），不进入通用规则
- 包抄：由寻路避让自然形成——接战/攻城单位进入射程后原地站定且不参与推开，成为避让障碍；后方行军单位经 RVO 水流式绕开交战线，从侧面包上（无主动包抄状态）
- 友军间距：RVO 避让 + 仅对双方均未接战的单位对逐帧推开（双方碰撞半径之和 + 4），避免堆叠
- 状态机：行军 Marching（含索敌）/ 接战 Fighting·Retaliating / 攻城 Sieging
- 攻击/攻城时原地站定（导航目标设为自身位置，不参与推开），不再绕目标漂移；推开位移同步回 Godot 节点

验收项：

- [x] 单位能绕开建筑到达目标
- [x] 目标选择统一取视野内最近敌人
- [x] 包抄行为生效
- [x] 友军不再重叠堆叠

## B6 特殊行动

目标：刺客隐身渗透（首个特殊行动）。

细化步骤：

1. 隐身状态：离敌方单位一定距离时自动进入隐身，敌方无法将其选为攻击目标
2. 隐身期间穿过敌方战线，直袭后排远程单位
3. 破隐规则：攻击时破隐；被 AOE 伤害命中时破隐；敌方有反隐单位时无法隐身
4. 隐身期间移动速度略微降低

- [ ] 攻击 / AOE / 反隐三种破隐规则全部生效
