# 当前任务：v0.5 部落·兽人线（第二派系）

阶段说明：v0.4 神殿卫士已收尾（实测阶段按用户要求跳过）。v0.5 实现第二派系——部落，本版先做**兽人线**（部落五族之一，基石前排）。设计基准见 `devPlan/design/factions/hordeFaction.md` 第 4.2 节。

## 统一进阶规则（本次同时落进设计文档与旧数据）

- **组合 vs 升级由入边数自动判定**：高级建筑入边 > 1 条（由多个低级建筑连线构成）= 组合；入边 = 1 条 = 升级。**不存在同类建筑双融合**
- 每个建筑有**唯一设定价值**，同时也是商店价格；编辑器新增/修改建筑时可直接编辑价值
- **升级费用 = 高级建筑价值 − 低级建筑价值**，自动计算，不单独配置
- **组合结果的价值按数据库设定**（不取组合物价值之和），组合本身免费
- 现有 `combine_recipes` 中同类双融记录（main = material）迁移为升级关系；跨线记录（main ≠ material）保留为组合

前置缺口（调研发现）：当前游戏**没有玩家派系选择入口**，商店卡池全量加载（`GameDataLoader.ShopCatalog` 不加过滤），所有玩法数据隐含为联盟。要让部落成为可玩派系，必须先补「派系选择 + 商店按派系过滤」。

进度：阶段一（数值与机制定稿）与阶段二（数据层 + 旧数据迁移）已完成；阶段三（domain 空地邻接 + 升级 + 狂怒 + 光环）已完成并通过全部单测。OrcCamp 商店条目暂未写入 `shop_catalog`（派系过滤未实现前避免污染联盟商店），待阶段六完成后再加回。

- 兽人线数值写入 `hordeFaction.md`：兽人营地/兽人要塞的 HP、产兵间隔与价值；兽人战士/狂战士的血量、伤害、速度、射程/攻击间隔、视野、体型、护甲（Heavy，钝击伤害）

## 二、数据层（config.db）与旧数据改造

- `building_defs`、`tech_tree_nodes` 新增 `value` 列（唯一价值 = 商店价）；编辑器新增/编辑建筑时读写该列
- `unit_stats` 新增 2 条单位：兽人战士、兽人狂战士，`race` 统一 orc，伤害类型钝击、护甲 Heavy
- 新增升级配方表（`upgrade_recipes`：source_type_id、result_type_id，主键 source+result，无费用列，费用由价值差自动计算；faction 经 `tech_tree_nodes` 关联）
- **旧数据改造**：`combine_recipes` 中 main = material 的记录全部迁移为 `upgrade_recipes` 升级边；main ≠ material 的跨线记录保留为组合边；联盟 T2+ 建筑补 `value`（按设计设定，非组合物之和）
- `tech_tree_nodes` + `shop_catalog`：兽人营地 T1 开局可买（3g，权重 12，value=3）；兽人要塞 T2 不进商店（value=7），仅升级获得
- `skill_defs` + `unit_skills`：狂怒（stat_modifier，低血量提升攻击）、狂怒共鸣（aura，周围友军 +10% 攻击）
- `ITechTreeRepository`/`SqliteTechTreeRepository` 扩展：`LoadUpgradeEdges(factionId)`、`SaveUpgradeEdges(factionId, edges)`，与组合边读写并行、互不干扰

## 三、domain 层：空地邻接 + 升级 + 狂怒 + 光环

- 空地邻接规则（`HordeAdjacencyRules`）：建筑四向邻接格为空地则产兵加速，每格 -12%，最多 -48%；邻接建筑/城堡无加成
- 升级规则（`UpgradeRules`/`UpgradeUseCase`）：读 `upgrade_recipes` 与双方价值，升级费 = 高级价值 − 低级价值，自动扣费；就地升级保留位置与当前血量百分比，随时可升、不依赖合成阶段；部落建筑不参与组合
- 狂怒：`stat_modifier` 低血量触发，攻击力随血量降低提升，T2 额外攻速提升
- 狂怒共鸣：`aura` 类型光环，周围友方部落单位 +10% 攻击；同种族不叠加、跨种族可累加（光环框架需支持多光环叠加）
- 组合规则按入边判定：`combine_recipes` 仅存跨线组合；组合结果价值取数据库设定值

验收项：

- [x] 空地邻接测试：0/1/2/4 空地产速倍率正确、建筑/城堡邻接无加成
- [x] 升级测试：费用=价值差正确扣除、位置与血量百分比保留、合成阶段不受影响
- [x] 狂怒测试：T1/T2 攻击加成阈值与上限正确、攻速提升正确
- [x] 光环测试：同种族不叠加、不同种族累加、范围外不生效

## 四、科技树编辑器扩展（dev 工具）

- 编辑器**不需要**连线类型切换或升级费用编辑交互；保存时按入边数自动分类：入边 > 1 → `combine_recipes`，入边 = 1 → `upgrade_recipes`
- 画布上组合边与升级边用不同颜色区分（如组合沿用白/橙，升级用青色），帮助理解
- 节点新增/编辑对话框增加**价值**字段（= 商店价），升级费用由价值差自动得出并在界面上展示
- 节点层级移动时，两类边的无效连线都要清理；节点移除时，两类关联边都要删除
- 保存时分别落 `combine_recipes` 与 `upgrade_recipes`，切换派系时分别加载
- 同步更新 `devPlan/design/devTools.md` 与 `combineSystem.md` 编辑器说明
